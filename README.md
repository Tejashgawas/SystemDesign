# SystemDesign
This source uses a relational analogy of a pizza restaurant to introduce the fundamental concepts of distributed systems and high-level architecture. It explains that vertical scaling involves enhancing existing resources, whereas horizontal scaling expands capacity by adding more machines to the network. The author outlines the importance of microservices for dividing responsibilities and load balancers for efficiently routing traffic based on real-time demands. To ensure reliability, the text suggests decoupling systems to remove single points of failure and using geographic distribution to reduce latency for global users. Ultimately, the guide distinguishes between high-level design, which focuses on system interactions, and low-level design, which deals with specific coding implementation.
